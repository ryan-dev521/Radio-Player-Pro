# 🎵 RadioApp (React + Vite)

A modern, responsive radio streaming web app built with React, Vite, and the Radio Browser API.  
Users can browse stations by genre, play live streams, and save favorites with a smooth UI experience including a draggable player window and theme switching.

---

## ✨ Features

- 📻 Live radio streaming (via Radio Browser API)
- 💃 Genre-based browsing (Dance, House, Pop)
- 🔍 Real-time station search filtering
- ❤️ Favorite stations (saved in localStorage)
- 🪟 Draggable, resizable player window
- 🎧 Persistent audio playback across navigation
- 🌗 Theme toggle (Aero glass / Dark mode)
- 📊 Visual audio indicators while playing
- ⚡ Responsive UI with animated components

---

## 🧠 Tech Stack

- **React (Vite)**
- **React Router**
- **Tailwind CSS**
- **radio-browser-api**
- **file-saver**
- **react-draggable**
- **JavaScript (ES6+)**
